PoC: Origin Spoofing in Permission Choosers via about:blank Popup

This PoC demonstrates that permission dialogs for a wide range of browser APIs do not display the correct requesting origin when invoked from an about:blank popup window.

Expected (secure): every permission prompt displays the requesting origin (https://your-domain.example).

Observed (vulnerable): many prompts show no origin at all, or show about:blank / null / about:srcdoc.

Steps:
  1. Click the button to open the about:blank popup.
  2. Click each 🔴 entry — inspect whether the permission chooser shows the origin or not.
  3. Click each ✅ entry as baseline — those should correctly show the origin.
  4. Click ℹ️ Diagnostic to see location.href vs location.origin inside the popup.
Requirements: Chromium-based browser, served over HTTPS or localhost.
Platform notes: NFC & Contact Picker — Android Chrome; Passkey — needs platform authenticator (Windows Hello / Touch ID / Android biometric); USB/Serial/HID/Bluetooth/MIDI — desktop Chromium; Idle Detection — desktop Chrome; Orientation/Motion — iOS Safari (prompts), desktop (no prompt).

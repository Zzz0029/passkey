📷 QR → about:blank → Eksekusi

⚠️ SECURITY RESEARCH TOOL — Jalankan hanya di localhost / domain Anda sendiri. Popup yang dieksekusi memiliki akses ke window.opener.
Butuh: HTTPS atau localhost (secure context) · Chromium desktop · kamera · izin popup.

Cara kerja

  1. Klik tombol di bawah → popup about:blank terbuka.
  2. Di dalam popup: klik Start Camera → arahkan ke QR code.
  3. QR terdeteksi → klik Execute.
  4. Kode berjalan di dalam popup about:blank.
  5. Permission dialog (Bluetooth/USB/Serial/Passkey/dll.) yang muncul menampilkan about:blank, bukan domain Anda → bug terbukti.

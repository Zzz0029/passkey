📷 QR → about:blank JavaScript Executor

⚠️ SECURITY RESEARCH TOOL — JANGAN DEPLOY PUBLIK
Tool ini mengeksekusi arbitrary JavaScript dari QR code di popup about:blank. Tujuannya untuk membuktikan bahwa permission prompt (Bluetooth, USB, Passkey, dll.) yang dipanggil dari about:blank tidak menampilkan origin.
Jangan scan QR yang tidak Anda buat sendiri. Kode yang dieksekusi punya akses ke window.opener, cookie, dan storage situs ini. Host hanya di localhost atau domain tanpa data sensitif.
Butuh: HTTPS atau localhost (secure context) · Chromium desktop (BarcodeDetector + permission API) · izin kamera.
